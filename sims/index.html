    List of MicroSims for Algebra I

    Interactive Micro Simulations to help students learn algebra i fundamentals.

    • Absolute Value Interactive Number Line

      Understand absolute value as distance from zero using an interactive number line with dynamic measurement.

    • Algebra Concept Viewer

      Interactive network visualization of Algebra I concepts and their prerequisite dependencies using vis-network.

    • Coordinate Plane Explorer

      Interactive tool for exploring points, axes, coordinates, and the four quadrants of the Cartesian coordinate system.

    • Coordinate Plane Interactive Plotter

      Practice plotting points on the coordinate plane and identifying quadrants.

    • Distributive Property Visual Model

      Visualize the distributive property using area models (rectangles) to show why a(b + c) = ab + ac.

    • Distributive Property Visualizer

      Visual area model demonstrating the distributive property of multiplication over addition with algebraic terms.

    • Distributive Property Visualizer MicroSim

      Visualize the distributive property using area models and step-by-step algebraic expansion.

    • Domain and Range Interactive Visualizer

      Help students visualize domain and range for various function types and understand restrictions.

    • Exponent Laws Practice Game

      Apply the laws of exponents to simplify expressions through interactive practice.

    • Exponent Types Interactive Explorer

      Explore how different types of exponents (positive, zero, negative) affect the value of powers.

    • Expression Explorer MicroSim

      Help students identify and understand the different parts of an algebraic expression interactively.

    • Expression Parts Explorer

      Interactive exploration of algebraic expressions, identifying terms, coefficients, variables, and constants.

    • FOIL Method Interactive Visualizer

      Master the FOIL method through visual representation and practice.

    • Function Evaluation Practice MicroSim

      Provide interactive practice for evaluating functions at different input values.

    • Function Transformations Interactive Explorer

      Help students visualize and understand function transformations by manipulating parameters and seeing real-time graph changes.

    • High School Courses Dependency Graph

      Interactive visualization mapping prerequisite relationships between high school mathematics and science courses.

    • Integer Operations on the Number Line

      Visualize integer addition and subtraction as movements on the number line.

    • Integer Operations on the Number Line

      Interactive horizontal number line demonstrating integer addition, subtraction, and directional movement from -10 to +10.

    • Interactive Coordinate Plane Explorer

      Help students understand the structure of the coordinate plane, including quadrants, axes, origin, and point location.

    • Interactive Line Graphing Practice

      Practice graphing linear equations using all three methods (intercepts, slope-intercept, table of values).

    • Intercepts and Graphing Interactive Practice

      Help students find intercepts algebraically and use them to graph linear equations.

    • Learning Graph Viewer

      Interactive visualization of the complete 200-concept Algebra I learning graph with search, zoom, and dependency traversal.

    • Like Terms Matching Game MicroSim

      Help students practice identifying and combining like terms through an interactive matching and simplification game.

    • Linear Equation Forms Converter and Grapher

      Help students convert between different forms of linear equations and understand when each form is most useful.

    • Number Systems Diagram

      Interactive Mermaid flowchart diagram mapping the hierarchical classification and properties of real and complex number systems.

    • Number Systems Hierarchy Diagram

      Visual nested Venn diagram illustrating the relationships between natural numbers, whole numbers, integers, rational numbers, and real numbers.

    • Number Systems Hierarchy Diagram

      Number Systems Hierarchy Diagram.

    • Number Systems Venn Diagram

      Interactive p5.js Venn diagram illustrating nested subsets from natural numbers to complex numbers.

    • Number Types Venn Diagram

      Interactive p5.js simulation demonstrating classification and set inclusion across rational and irrational numbers.

    • Order of Operations Challenge MicroSim

      Practice applying the order of operations (PEMDAS) through interactive step-by-step problem solving.

    • Parent Functions Reference Gallery

      Parent Functions Reference Gallery.

    • Piecewise Function Interactive Grapher

      Help students understand piecewise functions by building, visualizing, and evaluating them interactively.

    • Polynomial Classification Game

      Identify and classify algebraic expressions as monomials, binomials, trinomials, or non-polynomials.

    • Polynomial Classification Game

      Interactive classification challenge testing student ability to classify algebraic expressions as monomials, binomials, or trinomials.

    • Polynomial Classification Interactive Tool

      Practice identifying degree, leading coefficient, and standard form of polynomials.

    • Prime Factorization Tree Builder

      Interactive tree builder decomposing composite numbers into their prime factors step-by-step.

    • Prime Factorization Tree Builder MicroSim

      Practice building factor trees to find prime factorization of composite numbers through interactive tree construction.

    • Properties Practice Interactive Game

      Identify and apply mathematical properties in various equations and expressions.

    • Radical Simplification Interactive Tool

      Learn to simplify radical expressions by identifying and extracting perfect square or perfect cube factors.

    • Rational Number Classification Interactive

      Decide whether each number is rational, write the rational ones as p/q, and see why with a number line, a zoomed view, a fraction bar, and step-by-step explanations.

    • Real-World Function Modeling Interactive Scenarios

      Apply function concepts to model and solve real-world problems across various contexts.

    • Relation vs. Function Comparison Diagram

      Relation vs. Function Comparison Diagram.

    • Scientific Notation Converter and Calculator

      Practice converting between standard form and scientific notation, and perform operations with numbers in scientific notation.

    • Slope Visualizer and Calculator

      Help students visualize slope, understand rise/run, and calculate slope between two points.

    • Special Lines Explorer: Horizontal and Vertical

      Help students understand horizontal and vertical lines, their equations, slopes, and special properties.

    • Special Products and Factoring Matcher

      Recognize special product patterns and connect multiplication to factoring.

    • Variable Types Interactive Infographic

      Interactive visual guide showing different types of variables and their uses in real-world contexts with a 2x2 grid layout.

    • Vertical Line Test Interactive MicroSim

      Help students understand and apply the vertical line test to determine if a graph represents a function.

    • Write Equation of a Line Practice Scenarios

      Practice writing equations of lines given various types of information.
