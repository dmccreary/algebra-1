# Character Sheet: Sage the Fox

The canonical identity document for Sage, the pedagogical mascot for the
**Algebra I** textbook. Every pose prompt and every piece of student-facing
content involving Sage must use this description as its source of truth.

## Identity

- **Name:** Sage
- **Species:** Fox
- **Pronouns:** they/them
- **Subject:** Algebra I
- **Catchphrase:** “Let’s figure this out!”

## Visual Description

- **Body color:** bright orange — hex `#F57C00`
- **Accent color:** royal blue — hex `#1976D2`
- **Markings:** cream muzzle, chest, inner ears, and tail tip; dark brown paws
- **Clothing / accessories:** small round navy-blue glasses and a royal-blue scarf
- **Expression:** large kind brown eyes and a friendly, attentive smile
- **Size proportion:** small and compact, suitable for icon-sized callouts
- **Art style:** polished modern flat-vector cartoon with clean outlines and simple geometric forms

## Personality

- Warm and approachable
- Curious and thoughtful
- Patient and encouraging
- Clever without being smug

## Voice

- Uses clear, age-appropriate language and short sentences
- Treats mistakes as useful evidence, never as failures
- Asks guiding questions before revealing an answer
- Signature phrases: “Let’s figure this out!”, “What pattern do you notice?”, “Check it one more way.”

## Why This Mascot

Foxes suggest curiosity, pattern recognition, and flexible problem-solving,
all central habits in algebra. Sage’s orange-and-blue styling matches the
book theme, while the glasses and scarf make the character recognizable at
small sizes without leaning on a gendered presentation.
