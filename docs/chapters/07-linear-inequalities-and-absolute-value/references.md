# References: Linear Inequalities and Absolute Value

1. [Inequality (mathematics)](https://en.wikipedia.org/wiki/Inequality_(mathematics)) - Wikipedia - Comprehensive overview of inequality notation, properties, and the rule for reversing the symbol when multiplying or dividing by a negative number, foundational to this chapter's core topic.

2. [Absolute value](https://en.wikipedia.org/wiki/Absolute_value) - Wikipedia - Detailed explanation of absolute value as distance from zero, its algebraic properties, and formal definition, supporting the chapter's treatment of absolute value equations and inequalities.

3. [Interval (mathematics)](https://en.wikipedia.org/wiki/Interval_(mathematics)) - Wikipedia - Explains interval notation such as open, closed, and half-open intervals used to express solution sets of linear and compound inequalities graphed on a number line.

4. Algebra 1 (Common Core Edition) - Randall I. Charles - Prentice Hall/Pearson - Chapter on solving and graphing inequalities presents one- and two-step inequalities, compound inequalities, and absolute value equations with guided practice matching this chapter's sequence.

5. Big Ideas Math: Algebra 1 - Ron Larson and Laurie Boswell - Big Ideas Learning - Includes a dedicated unit on solving linear inequalities, compound inequalities, and absolute value equations and inequalities with worked examples and real-world applications.

6. [Solving Linear Inequalities](https://www.mathsisfun.com/algebra/inequality-solving.html) - Math Is Fun - Tutorial explaining the rules for solving inequalities, including why the inequality symbol reverses when multiplying or dividing by a negative number, directly reinforcing this chapter's key exception rule.

7. [Absolute Value](https://www.mathsisfun.com/numbers/absolute-value.html) - Math Is Fun - Introduces absolute value as distance from zero with numeric examples and notation, providing the conceptual groundwork needed before solving absolute value equations in this chapter.

8. [Solving Simpler Absolute-Value Equations](https://www.purplemath.com/modules/solveabs.htm) - Purplemath - Step-by-step lesson on splitting an absolute value equation into two cases and checking solutions, matching the chapter's method for solving equations like |x + 3| = 5.

9. [Compound Inequalities: Graph, AND, OR, Examples & FAQs](https://www.geeksforgeeks.org/maths/compound-inequality/) - GeeksforGeeks - Explains AND (intersection) and OR (union) compound inequalities with graphing techniques and worked examples, aligning with this chapter's coverage of compound inequality logic.

10. [Absolute Value Inequalities](https://www.geeksforgeeks.org/maths/absolute-value-inequalities/) - GeeksforGeeks - Covers solving and graphing absolute value inequalities of both the "less than" and "greater than" types, directly supporting the chapter's rules for converting them into compound inequalities.
